Optional right-click convenience

The context-menu API permission is requested when the extension is installed. Enabling this option additionally requests Firefox's active-tab and scripting permissions. The paste workflow does not require them.

Loopback services and api.openai.com have default host access. Saving another HTTPS provider asks Firefox for access to that provider origin. If access is denied, enable the origin in this extension's Permissions and data settings in about:addons, then save again.
